The MIT license in this repository covers the original CatProof source. It does not replace the licenses of Python, PostgreSQL, Caddy, Python dependencies, system libraries or other upstream software used to build and run the distribution.

Python dependencies are listed with exact versions in `requirements.txt`. Their distributions include their own metadata and license notices. Base container images retain their upstream software and notices. Published image builds request an SBOM and build provenance so users can inspect included components. Review the actual image and its dependency metadata for the release you deploy.
