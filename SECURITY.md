# Security reporting

Do not publish exploitable vulnerabilities or sensitive evidence in a public issue. Contact **info@catproof.ai** with a description, affected release and a reproduction using synthetic data. Never send live credentials or database exports. The maintainers will coordinate next steps; no response-time guarantee is implied.

Only the current published Community Edition release is a maintenance target during early access. Review release notes for fixes. This laptop bundle binds to loopback and is not an internet-facing deployment guide.

Use narrowly scoped provider credentials. Preserve the connector encryption key and protect database backups. Do not disable HTTPS, authentication or network restrictions to work around setup errors.
